{%- comment -%} Concept 3 indicator cover (T-0556 w2). One include for every cover on the site, fed by catalog.yml `cover_label` (a one- or two-word name of the report's main threat or risk), so a change of label is a data edit. Params: label (real, reader-facing text), severity (critical|high|med|low, picks the edge colour), size (lead|row|header), kicker (optional small line over the label), hex (optional text the texture is made from, default the label). The faint hex texture is decoration: the 
 is aria-hidden, empty in the HTML and filled by assets/js/c3-cover.js from data-hex, so no text of it reaches a reader, a search index or a crawler. Block elements only, so it sits inside a link. {%- endcomment -%}
