{%- comment -%} PROVIDER CONCENTRATION COMPONENT Renders a report's `provider_concentration` front matter as a static, semantic, CSS-drawn cumulative-concentration strip. Built for the case where a reader has to hold several related quantities in their head to see a distribution shape (here: how few provider groups cover most of a confirmed-victim population) before a disclosure consequence lands. NOT a chart library, NOT an image, NOT JavaScript. Every number is real, selectable HTML text; the bar's width only supplies the at-a-glance shape. A reader must be able to copy every figure as text, and the labels must read correctly with the bars removed entirely (images off, an Atom feed reader, a screen reader), which is why every `pc-track`/`pc-fill` element is `aria-hidden="true"`: the number it visualises is already present as text immediately beside it. Pairs with assets/css/custom.css (PROVIDER CONCENTRATION COMPONENT block). No
here: unlike the two-axis and install-modes components, there is no deeper prose to hide behind a toggle, so nothing needs to expand or collapse and nothing needs a forced "open" rule at print time. USAGE, from a report's markdown. Wrap it in the report's own
